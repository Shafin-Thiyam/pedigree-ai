# Pedigree AI

AI-powered genetic pedigree generation and management platform.

## Technology Stack

- Python 3.12
- FastAPI
- Pydantic
- PostgreSQL
- SQLAlchemy
- NetworkX
- MCP
- LLM integration

## Development Setup

### Create virtual environment

python -m venv .venv

### Activate

Windows Git Bash:

source .venv/Scripts/activate

### Install dependencies

pip install -e ".[dev]"

### Run tests

pytest
